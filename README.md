# Ruby 2.0

Ruby uses the browser microphone and speech synthesis for voice, and a Cloudflare Worker for Gemini replies. She also accepts typed messages. The Worker serves the app and chat API on the same HTTPS address.

## Deploy to Cloudflare

Run these from the repository root using current Wrangler 4 and an authenticated Cloudflare account. The repository targets the existing `rubyaibrain` Worker. Review the existing Worker's settings before replacing its deployment.

1. Run `npx wrangler@4 deploy`. The chat API fails closed until both secrets are present.
2. If that Worker does not already have the `GEMINI` secret, run `npx wrangler@4 secret put GEMINI` and paste the Gemini API key at the prompt.
3. Run `npx wrangler@4 secret put RUBY_ACCESS_CODE` and enter a unique password generated by your password manager. Enter it at the secret prompt only.
4. Open the HTTPS URL printed by Wrangler. Enter the Ruby access code in Settings, send a text message, then test the microphone and spoken reply in Safari.

The default model is `gemini-3.1-flash-lite`. Set the optional `GEMINI_MODEL` Worker variable to a model available to your Gemini project if needed. Wrangler preserves existing dashboard variables on deploy.

Use the Worker URL for Ruby 2.0. The original GitHub Pages address hosts the prototype. Browser history is scoped to each site's address, so existing GitHub Pages history stays at that address. Ruby 2.0 saves its own recent chat on the device and sends up to 12 recent entries to Gemini along with each message. The access code is held in the open page and needs to be re-entered after a reload. Browser voice features depend on the voices and speech recognition available on that device.
